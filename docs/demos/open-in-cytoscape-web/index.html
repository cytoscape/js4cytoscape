Open in Cytoscape Web

Same network as the desktop demo — a 6-node cell hierarchy — but no install required. Cytoscape Web runs entirely in the browser, so the “integration” is literally a hyperlink.

How this works: there is no 127.0.0.1:1234 bridge for Cytoscape Web. Instead, you hand it a URL — either a network already in NDEx, or any CX2 file the browser can fetch.

1. Open from URL (simplest case)

Host a CX2 file anywhere reachable over HTTPS (S3, GitHub Pages, your CDN, NDEx, …) and pass its URL to Cytoscape Web via the ?import= query parameter. No auth, no library required.

2. Open via NDEx UUID (recommended when your app has user accounts)

If your app already stores user networks in NDEx, the link carries just the UUID. Cytoscape Web fetches the network from NDEx for you. Private networks work too — append ?accesskey=<key>.

In a real web app, the UUID above is produced by uploading the CX2 to NDEx with @js4cytoscape/ndex-client: 

import { NDExClient } from '@js4cytoscape/ndex-client';

const client = new NDExClient({ baseURL: 'https://www.ndexbio.org' });
client.updateConfig({ auth: { type: 'BASIC', username, password } });

// Save the user's CX2 and get back the new network's UUID.
const { data: uuid } = await client.network.createNetworkFromCX2(cx2);

// Hand the UUID to Cytoscape Web.
window.open(`https://web.cytoscape.org/0/networks/${uuid}`, '_blank');

3. Open with pre-set view state (advanced)

The URL can also carry view state: which panels are open, which nodes are pre-selected, which tab in the table browser is active, whether the filter panel is enabled, and more. Useful for deep-linking from reports, papers, and email.
