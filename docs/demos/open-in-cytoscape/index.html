Open in Cytoscape

Click Open in Cytoscape to send a small CX2 network — a 6-node cell hierarchy (Cell → organelles → chromosome / nucleolus / gene) — to your running Cytoscape Desktop via CyREST. Then click Apply Hierarchical Layout to lay it out as a tree with the root on top.
